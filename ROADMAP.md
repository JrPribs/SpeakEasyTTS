# SpeakEasy TTS - Product Roadmap

## Current Version (v1.0)
- ✅ Menu bar app with Edge TTS neural voices
- ✅ Floating always-on-top overlay widget
- ✅ Read selected text (Accessibility API)
- ✅ Read from clipboard
- ✅ Play/Pause/Stop controls
- ✅ Multiple voice options
- ✅ Speed/pitch controls
- ✅ Visual indicator when text is selected (turns green)

---

## Phase 2: Enhanced Text Selection
**Priority: High**

### Auto-Read on Selection
- [ ] Configurable option to auto-read when text is selected
- [ ] Hotkey to instantly read selection (e.g., Option+S)
- [ ] Double-tap widget to read selection

### Browser Integration
- [ ] Browser extension for full page text extraction
- [ ] Read entire article (not just visible text)
- [ ] "Reader mode" text extraction
- [ ] Support for Safari, Chrome, Firefox

---

## Phase 3: AI Text Processing
**Priority: Medium-High**

### Content Cleaning
- [ ] AI-powered ad/irrelevant content removal
- [ ] Extract main article content from web pages
- [ ] Remove navigation, headers, footers, sidebars
- [ ] Clean up formatting artifacts

### Text Summarization
- [ ] Option to summarize long text before reading
- [ ] Adjustable summary length
- [ ] Key points extraction mode

### Text Enhancement
- [ ] Fix OCR errors if reading from screenshot
- [ ] Add natural pauses at paragraph breaks
- [ ] Pronunciation improvements for technical terms

---

## Phase 4: Advanced Features
**Priority: Medium**

### Screenshot-to-Speech
- [ ] OCR integration (Vision framework)

### Contextual Awareness
- [ ] Detect active application

- [ ] Remember position in long documents

### Voice Cloning
- [ ] Custom voice training
